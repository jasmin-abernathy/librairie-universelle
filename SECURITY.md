# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the project is in alpha.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Send a private report to `contact@lepotager.org` with the subject `Security — Librairie universelle`. Include the affected commit, reproduction steps, impact and any mitigation you have identified.

Do not send real author manuscripts, admin tokens, production databases or personal data. Use minimal synthetic examples.

Particular attention should be paid to upload handling, path traversal, stored files outside the web root, admin authentication and imported third-party data.
