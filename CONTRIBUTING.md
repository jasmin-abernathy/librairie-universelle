# Contributing

Contributions are welcome for cataloguing, source adapters, accessibility, tests, documentation and the independent-publishing workflow.

Please preserve the project's core rules:

- no behavioural profiling or targeted advertising;
- no AI-generated ranking, recommendations or editorial validation;
- never invent prices, stock, rights status or partner relationships;
- keep source provenance and freshness explicit;
- do not commit manuscripts, production databases, admin tokens or personal data;
- use fixtures and synthetic files for tests;
- keep public-domain checks conservative when legal status is uncertain.

Run the available test suite before proposing a change. Report vulnerabilities privately using `SECURITY.md`.

Contributions are provided under AGPL-3.0-only.
